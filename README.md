# BTS Config Generator 🛠️

![Python](https://img.shields.io/badge/python-3.8+-blue.svg)
[![Code Style](https://img.shields.io/badge/code%20style-PEP%208-brightgreen.svg)](https://pep8.org)

Генератор конфигураций для базовых станций с поддержкой:
- UML-моделей в XML
- Автоматической валидации
- Генерации артефактов

## 🚀 Запуск программы

Программа запускается **исключительно через main.py**:

```bash
python main.py
```

## 🌟 Особенности

- **Конфигурация из UML**  
  Преобразование XML-моделей в рабочие конфигурации

- **Умное сравнение версий**  
  Детектирование изменений между конфигурациями

- **Готовые артефакты**  
  Генерация файлов для всех компонентов системы

- **Гибкая архитектура**  
  Легкое расширение под новые форматы

- **Чистая архитектура с разделением ответственностей**  
  Весь основной код вынесен из main.py в отдельные модули  
  В main.py осталась только точка входа

## 📂Содержимое папки `out/`:

```plaintext
📂out/
├──📄config.xml              # Конфигурация системы
├──📄meta.json               # Метаданные для UI
├──📄delta.json              # Изменения между версиями
└──📄res_patched_config.json # Объединённая конфигурация
```

## 🏗 Структура `src/`:

```plaintext
📂src/
├──📂core/       # Логика приложения
├──📂generators/ # Генерация файлов
├──📂models/     # Модели данных
├──📂parsers/    # Парсер входных данных
└──📂utils/      # Вспомогательные функции
```

## 🧩Технологии
- Python 3.8+
- Стандартная библиотека
- XML/JSON обработка
- Dataclasses для моделей
